## What is covered

| Area | Tests | What they prove |
|---|---:|---|
| Incident replay | 9 | Each step of the reconstructed Hugging Face attack chain gets the expected verdict: 8 BLOCK, 1 ALLOW for the legitimate first step |
| Benign workloads | 10 | Everyday actions pass (`pytest`, `git status`, `ls`, `npm test`, a source-file write, an allowlisted API call). `rm -rf build/` is routed to REVIEW, not blocked |
| Shell rules | 11 | Disk wipe, fork bomb, reverse shell, PowerShell `iex`, `wevtutil cl`, `unset HISTFILE`, log overwrite, `sudo`, AWS creds, `authorized_keys`, `--privileged` container |
| File / network policy | 5 | Workspace confinement, path traversal, system-path writes (POSIX + Windows), domain allowlist and subdomains, raw-IP egress, secrets in outbound payloads |
| Prompt injection | 1 | Zero-width characters (override phrases and hidden comments are also covered in the incident replay) |
| Tamper-evident audit log | 5 | The hash chain detects **edits, deletions, garbage lines** and, with a published head-hash anchor, **tail truncation** |
| `@guard` decorator | 2 | Blocks before the wrapped function runs, raises `ReviewRequired`, and supports positional and keyword arguments |
| Local LLM reviewer | 7 | Can escalate but **never blocks alone**. Isn't consulted when the rules already block. Fails safe if Ollama is down. Parses and clamps JSON. Handles tag matching. Includes **1 live test against real `llama3.2`**: a malicious `id_rsa` exfil is rated riskier than `ls` |
| CLI and JSON stdin | 6 | Exit codes 0/1/2/3/4, `--json` output, `verify` catches a tampered log. Stdin accepts a single object, an array and JSON Lines, returns the worst exit code for a batch, and rejects malformed input with exit 4 |
| Input validation | 1 | Unknown action kinds are rejected |
| Attribution | 1 | Package metadata credits LalithPrabu |

## Known limits (not defects)

- The regex rules can be evaded by deliberate obfuscation. Sentinel is a defence-in-depth layer, not a sandbox.
- The live-LLM assertion is relative (malicious > benign), not an absolute score, because small local models vary.
